# E-commerce-Sales-Analysis:
 
# Project Overview:
This project analyzes e-commerce sales data to uncover business insights related to sales performance, profitability, customer segments, regional performance, and top-selling products.
The project was completed using:
- Excel
- SQL (BigQuery)
- Tableau
- GitHub

# Project Objective:
The objective of this project is to:
- Analyze sales and profit trends
- Identify high-performing product categories
- Evaluate regional profitability
- Understand customer segment contribution
- Discover top-selling products
- Create interactive dashboards for business decision-making

# Tools & Technologies Used:

Tool & Purpose :
Excel - Data Cleaning & Dashboard 
SQL (BigQuery) - Data Analysis 
Tableau - Interactive Dashboard 
GitHub - Project Documentation & Portfolio 

# Dataset Used:
Dataset: Sample Superstore Dataset
The dataset contains:
- Order Date
- Sales
- Profit
- Region
- Category
- Sub-Category
- Segment
- Product Name
- Quantity
- Discount

# Data Cleaning Process:
The following cleaning steps were performed in Excel:
- Removed duplicate records
- Checked missing values
- Standardized date format
- Created Year and Month columns
- Verified data types
- Created Profit Margin column

# Excel Dashboard Features:
The Excel dashboard includes:
- KPI Cards
- Monthly Sales Trend
- Sales by Category
- Profit by Region
- Segment Distribution
- Top 10 Products

# SQL Analysis:
SQL queries were used to analyze:
- Total Sales
- Total Profit
- Average Order Value
- Monthly Sales Trend
- Category-wise Sales
- Region-wise Profit
- Top Products

# Tableau Dashboard:
An interactive Tableau dashboard was created to visualize:
- Sales trends
- Category performance
- Regional profit analysis
- Customer segments
- Top-performing products

# Key Insights:
- Technology category generated the highest sales.
- West region produced the highest profit.
- Consumer segment contributed the highest revenue.
- Sales increased during the later months of the year.
- Top products contributed significantly to overall sales.

# Business Recommendations:
- Focus marketing on high-performing categories.
- Improve sales strategies in low-performing regions.
- Increase inventory for top-selling products.
- Target consumer segment with loyalty programs.
